# 文本、下拉与上传
根据已观察的标签、区域标题和角色精确定位。用支持的 fill 替换文本，保留手机号前导零和证件原文，不用 Tab 盲跳。React/Vue 输入使用用户式接口，失焦读回防止回滚。
原生 select 使用公开选择接口。搜索组合框按打开、输入关键词、读取结果、选中、核对标签处理；只输入关键词不算选中。
虚拟列表在列表内部滚动，逐次读取新选项。国家、省、市按父子依赖逐项等待更新。同名学校/公司核对校区及主体。
一批超时先确认页面和记录仍一致，再读回全部字段并补填。姓名邮箱正确时保留。选择国家重绘省市后重新定位。
上传先按用途、语言、版本、大小和格式匹配材料；本机路径和云端路径不同，不伪造路径。使用工具明确支持的上传接口，核对文件名与完成状态。重试前检查是否已经成功。
