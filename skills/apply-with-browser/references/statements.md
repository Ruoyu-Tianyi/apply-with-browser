# 陈述生成
读取题干、岗位要求、语言、上下限和子问题。选择1–3条有依据经历，按动机、本人行动、能力和岗位联系组织；行为题可用STAR。
允许翻译、改写和压缩，不编造证书、GPA、职责、成果比例、排名或团队贡献。缺量化结果用真实定性结果。用户允许自动生成填写时无需每题确认，填后读回。
个人项目不能编成团队冲突故事；事实不足的行为问题集中询问，不填占位符。薪资、签证、亲属、处分等身份事实不能靠文案推断。
遵守站点明确的独立作答及AI限制，不把陈述授权扩大为代做考试或虚假声明。
检查字数和字符口径：Unicode字符、UTF-16单元和英语词数不同，页面计数器优先。上下限均须满足；填后检查截断、换行、计数及保存结果，只局部修复。
